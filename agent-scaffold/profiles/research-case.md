Work folders:

```
00_inputs/originals/     given material — read-only; never upload, never paste into searches
00_inputs/extracted/     text extracts made once at init — read these, not the originals
01_context/              brief, research questions with ids (A1, B2…), framework
02_research/<stream>/    your finding files, from agents/templates/finding.md
03_synthesis/            matrix, patterns, mapping — written only after streams have drafts
04_deliverables/         the memo/brief for the recipient; `v<N>` only here, never overwrite a sent version
```

Research standards: primary sources first (filings, official pages, papers), then reputable press; mark type in `sources.md`. "Not found, searched X, Y, Z" is a result — write it. Every comparison field in the finding template filled or marked not found, so synthesis can compare side by side. Confidential inputs (deck content, meeting notes, hypotheses) never leave this folder: search public topics only.
Streams run in parallel: one agent, one sub-question, one file; source-id prefix per agent. The synthesizer reads finding files, does no new research, links every statement to its finding file. A verifier (clean context) checks a finding before it enters synthesis or the deliverable.
Day rhythm: `STATUS.md` checkpoints (first drafts → synthesis → deliverable → export). Spikes idle 2 days are flagged.
